# Gamedle - Public Showcase

Gamedle is a daily game-guessing experience for people who love video games.

Think of it like a game-discovery puzzle: each guess reveals clues that help players narrow in on the correct title.

## What the Project Includes

- Daily challenge mode
- Free-play mode
- User login and score tracking
- Leaderboard gameplay loop
- Data-backed clue system (genre, release timing, developer context)

## Stack

- Frontend: React, HTML, CSS, JavaScript
- Backend: Node.js
- Database: SQL
- Integrations: Game data APIs + authentication

## Roadmap Snapshot

- Functional baseline with database-backed verification
- Full browser UI with gameplay flow
- Daily mode + free mode + account progress
- Leaderboard support
- Future multiplayer challenge mode
